### 6장. 회원 관리 예제 - 웹 MVC 개발

#### 1. 회원 웹 기능 - 홈 화면 추가

홈 화면을 담당하는 컨트롤러 (`src/main/java/hello/hellospring/controller/HomeController.java`)
루트 경로(`/`)로 들어오는 GET 요청을 처리하여 홈 화면 뷰 템플릿을 연결한다.

```java
package hello.hellospring.controller;

import org.springframework.stereotype.Controller;
import org.springframework.web.bind.annotation.GetMapping;

@Controller
public class HomeController {

    @GetMapping("/")
    public String home() {
        return "home";
    }
}

```

* @GetMapping("/"): 웹 애플리케이션의 루트 경로(`/`)로 들어오는 GET 요청과 메서드를 매핑한다.
* return "home": 뷰 리졸버와 Thymeleaf가 `src/main/resources/templates/home.html`을 찾아 렌더링한다.

홈 화면 템플릿 (`src/main/resources/templates/home.html`)

```html
<!DOCTYPE html>
<html lang="ko">
<head>
    <meta charset="UTF-8">
    <title>Hello Spring</title>
</head>
<body>
<div class="container">
    <div>
        <h1>Hello Spring</h1>
        <p>회원 기능</p>
        <p>
            <a href="/members/new">회원 가입</a>
            <a href="/members">회원 목록</a>
        </p>
    </div>
</div>
</body>
</html>

```

* 컨트롤러 매핑 우선순위: 기존 `static/index.html` 정적 웰컴 페이지보다 `@GetMapping("/")`이 설정된 컨트롤러가 우선순위를 가진다.

#### 2. 회원 웹 기능 - 회원 등록

회원 등록은 등록 화면 조회(GET)와 등록 요청 처리(POST) 두 단계로 구분된다.

회원 등록 폼 컨트롤러 추가 (`src/main/java/hello/hellospring/controller/MemberController.java`)

```java
@GetMapping("/members/new")
public String createForm() {
    return "members/createMemberForm";
}

@PostMapping("/members/new")
public String create(MemberForm form) {
    Member member = new Member();
    member.setName(form.getName());

    memberService.join(member);

    return "redirect:/";
}

```

* @GetMapping("/members/new"): 회원가입 입력 폼 화면(`templates/members/createMemberForm.html`)을 반환한다.
* @PostMapping("/members/new"): 폼에서 POST 방식으로 전송된 데이터를 받아 회원을 등록하고 루트 페이지(`redirect:/`)로 리다이렉트한다.

폼 데이터를 전달받을 객체 (`src/main/java/hello/hellospring/controller/MemberForm.java`)

```java
package hello.hellospring.controller;

public class MemberForm {

    private String name;

    public String getName() {
        return name;
    }

    public void setName(String name) {
        this.name = name;
    }
}

```

회원 등록 폼 템플릿 (`src/main/resources/templates/members/createMemberForm.html`)

```html
<!DOCTYPE html>
<html xmlns:th="http://www.thymeleaf.org">
<body>
<div class="container">
    <form action="/members/new" method="post">
        <div class="form-group">
            <label for="name">이름</label>
            <input type="text" id="name" name="name" placeholder="이름을 입력하세요">
        </div>
        <button type="submit">등록</button>
    </form>
</div>
</body>
</html>

```

* input의 `name="name"` 속성을 기준으로 스프링이 `MemberForm`의 `setName()`을 호출해 값을 자동으로 바인딩한다.

#### 3. 회원 웹 기능 - 회원 목록 조회

회원 목록 조회 컨트롤러 추가 (`src/main/java/hello/hellospring/controller/MemberController.java`)

```java
@GetMapping("/members")
public String list(Model model) {
    List<Member> members = memberService.findMembers();
    model.addAttribute("members", members);
    return "members/memberList";
}

```

* `memberService.findMembers()`로 전체 회원 목록을 조회한 뒤, `Model` 객체에 `"members"` 키로 담아 뷰 템플릿(`members/memberList.html`)에 전달한다.

회원 목록 템플릿 (`src/main/resources/templates/members/memberList.html`)

```html
<!DOCTYPE html>
<html xmlns:th="http://www.thymeleaf.org">
<body>
<div class="container">
    <div>
        <table>
            <thead>
            <tr>
                <th>#</th>
                <th>이름</th>
            </tr>
            </thead>
            <tbody>
            <tr th:each="member : ${members}">
                <td th:text="${member.id}"></td>
                <td th:text="${member.name}"></td>
            </tr>
            </tbody>
        </table>
    </div>
</div>
</body>
</html>

```

* `th:each="member : ${members}"`: 모델에 담긴 `members` 리스트의 요소 개수만큼 `<tr>` 태그를 반복 렌더링한다.

### 7장. 스프링 DB 접근 기술

#### 1. H2 데이터베이스 설치 및 설정

H2는 자바 기반의 가벼운 관계형 데이터베이스이다.

실행 및 접속 방식

* macOS / Linux: `./h2.sh` (필요시 `chmod 755 h2.sh` 권한 부여)
* Windows: `.\h2.bat`
* 초기 DB 파일 생성 접속: `jdbc:h2:~/test`
* 이후 TCP 소켓 방식 접속: `jdbc:h2:tcp://localhost/~/test`

회원 테이블 생성 SQL (`sql/ddl.sql`)

```sql
DROP TABLE IF EXISTS member CASCADE;
CREATE TABLE member (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY,
    name VARCHAR(255),
    PRIMARY KEY (id)
);

```

* `GENERATED BY DEFAULT AS IDENTITY`: 메모리 저장소에서 자바 코드로 `++sequence` 하던 ID 자동 증가 역할을 DB가 대신 수행한다.

---

#### 2. 순수 JDBC

라이브러리 의존성 및 DB 접속 설정
`build.gradle`에 JDBC와 H2 드라이버 의존성을 추가한다.

```groovy
implementation 'org.springframework.boot:spring-boot-starter-jdbc'
runtimeOnly 'com.h2database:h2'

```

`src/main/resources/application.properties`에 DB 연결 정보를 설정한다.

```properties
spring.datasource.url=jdbc:h2:tcp://localhost/~/test
spring.datasource.driver-class-name=org.h2.Driver
spring.datasource.username=sa
spring.datasource.password=

```

순수 JDBC 리포지토리 구현 (`JdbcMemberRepository`)

* `DataSource`를 주입받아 DB 연결(`Connection`)을 획득하고, `PreparedStatement`로 SQL을 실행하며, `ResultSet`으로 조회 결과를 읽는다.
* DB 접근 실패 시 `SQLException`이 발생할 수 있으므로 `try-catch-finally` 블록에서 사용한 DB 자원(`conn`, `pstmt`, `rs`)을 반드시 반환해야 한다.

객체지향 설계 원칙의 적용

* 다형성: 동일한 `MemberRepository` 인터페이스로 메모리 구현체와 JDBC 구현체를 교체할 수 있다.
* 개방-폐쇄 원칙(OCP): 확장에는 열려 있고 수정에는 닫혀 있는 구조로, `SpringConfig`의 설정만 변경하면 기존 `MemberService`와 `MemberController` 코드를 수정하지 않고도 DB 저장소를 교체할 수 있다.

#### 3. 스프링 통합 테스트

`MemberServiceIntegrationTest` 구성

* `@SpringBootTest`: 스프링 컨테이너와 테스트 환경을 함께 실행하여 실제 DB 연결까지 통합 검증한다.
* `@Transactional`: 테스트 시작 시 트랜잭션을 시작하고, 테스트 완료 후 항상 롤백(Rollback)한다. 이를 통해 DB에 테스트 데이터가 남지 않아 다음 테스트를 반복 실행해도 영향을 주지 않는다.

단위 테스트 vs 통합 테스트

* 단위 테스트: 스프링 컨테이너나 외부 DB 없이 순수 자바 코드로 빠르게 로직을 검증한다.
* 통합 테스트: 스프링 빈 조립과 실제 DB 연동까지 전체 흐름을 검증한다.

#### 4. 스프링 JdbcTemplate

순수 JDBC API에서 반복되는 커넥션 획득, 자원 반납 등의 보일러플레이트 코드를 제거해 주는 스프링 기술이다. (SQL은 개발자가 직접 작성한다.)

주요 구현 방식

* 생성자에서 `DataSource`를 주입받아 `new JdbcTemplate(dataSource)`를 생성한다.
* 조회 시 `jdbcTemplate.query(SQL, RowMapper, 파라미터)`를 사용하여 조회 결과를 `Member` 객체로 매핑한다.
* 저장 시 `SimpleJdbcInsert`를 활용하면 별도의 `INSERT` SQL 작성 없이 테이블명과 PK 컬럼명만으로 데이터를 저장하고 생성된 키를 반환받을 수 있다.

#### 5. JPA

JPA(Java Persistence API)는 자바 진영의 ORM(Object-Relational Mapping) 표준 인터페이스로, 개발자가 SQL을 직접 작성하지 않고 객체 중심으로 데이터를 관리할 수 있게 해준다. (구현체로 주로 Hibernate를 사용한다.)

의존성 추가 (`build.gradle`)

```groovy
implementation 'org.springframework.boot:spring-boot-starter-data-jpa'
runtimeOnly 'com.h2database:h2'

```

엔티티 매핑 (`src/main/java/hello/hellospring/domain/Member.java`)

```java
package hello.hellospring.domain;

import jakarta.persistence.*;

@Entity
public class Member {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    private String name;

    public Long getId() {
        return id;
    }

    public void setId(Long id) {
        this.id = id;
    }

    public String getName() {
        return name;
    }

    public void setName(String name) {
        this.name = name;
    }
}

```

* `@Entity`: JPA가 관리하는 엔티티 클래스임을 명시한다.
* `@Id`, `@GeneratedValue(strategy = GenerationType.IDENTITY)`: 기본 키(PK)와 DB의 자동 생성 전략을 매핑한다.
* `@Transactional`: JPA를 통한 모든 데이터 변경(저장, 수정, 삭제)은 반드시 트랜잭션 안에서 실행되어야 하므로 `MemberService`에 `@Transactional`을 적용한다.

#### 6. 스프링 데이터 JPA

JPA를 한 단계 더 추상화하여 구현 클래스 없이 인터페이스만으로 기본적인 CRUD와 조회 기능을 제공하는 프레임워크이다.

리포지토리 인터페이스 작성 (`src/main/java/hello/hellospring/repository/SpringDataJpaMemberRepository.java`)

```java
package hello.hellospring.repository;

import hello.hellospring.domain.Member;
import org.springframework.data.jpa.repository.JpaRepository;

import java.util.Optional;

public interface SpringDataJpaMemberRepository extends JpaRepository<Member, Long>, MemberRepository {

    @Override
    Optional<Member> findByName(String name);
}

```

* 프록시 구현체 자동 등록: 스프링 데이터 JPA가 `JpaRepository`를 상속받은 인터페이스를 찾아 구현 객체를 자동으로 생성해 스프링 빈으로 등록한다.
* 메서드 이름 기반 쿼리 생성: `findByName(String name)`처럼 정해진 규칙에 따라 메서드 이름을 선언하면 `select m from Member m where m.name = :name` 형태의 JPQL을 자동으로 생성해 실행한다.

| DB 접근 기술 | 특징 |
| --- | --- |
| 순수 JDBC | 연결, SQL 작성, 결과 매핑, 자원 반납을 모두 직접 코드로 구현 |
| JdbcTemplate | 반복적인 연결 및 자원 반납 코드는 제거되나 SQL은 직접 작성 |
| JPA | SQL을 자동으로 생성하며 객체와 테이블을 매핑 (`EntityManager` 사용) |
| 스프링 데이터 JPA | 구현 클래스 없이 인터페이스만으로 공통 CRUD 및 메서드 이름 기반 조회 제공 |
